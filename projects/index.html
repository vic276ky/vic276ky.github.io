Cybersecurity Projects

GoldPhish - Phishing URL Detector

GoldPhish is a machine learning based phishing URL detector trained on 87,000+ real phishing URLs from PhishTank. Built with Python, Scikit-learn and Flask — it extracts 20 URL features and classifies any URL as phishing or legitimate in real time with a 99.34% accuracy. The web interface returns a risk score, confidence percentage and a breakdown of why the URL was flagged.
